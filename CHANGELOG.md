# 0.1.0 development snapshot

Initial portable Rust workspace; typed private IPC, minimal daemon/CLI, hardware probes, service-supervision library, signed owned-file update generations, six native Slint app entry points, Android document and host adapters, APatch packaging, build and validation workflows.

This is an incomplete developer snapshot. See docs/STATUS.md for unimplemented features and docs/DEVICE_TESTS.md for tests still required. No physical-device, battery, 120 Hz, daily-driver or bug-free claims.
